## Hub Module Overview

The `hub` directory contains two submodules that together form the **system of record** for the mana-hive platform.

### 1. hub-domain (`/home/visiona/workspace/mana-hive/hub/hub-domain/`)

**Build Configuration** (`build.gradle.kts`):
- Uses the `manahive.pure-domain` plugin (pure domain logic, no framework dependencies)
- Depends on `platform.domainKernel` and `platform.contracts`

**Source Files**:
- **`PolicyResolver.kt`** - The core domain logic for resolving clinical policy rules for a resident at a specific time. Key aspects:
    - Implements the `Engine` interface
    - Uses layered resolution with deterministic precedence: watch level → level template → manual adjustments → time windows
    - Tie-break rule: the most protective layer wins
    - Data classes: `PolicyLayers`, `LevelTemplate`, `ManualAdjustment`, `TimeWindow`

**Role**: Pure domain logic for clinical policy resolution. This is the "brain" that determines which rules apply to a resident based on multiple layered inputs.

---

### 2. hub-service (`/home/visiona/workspace/mana-hive/hub/hub-service/`)

**Build Configuration** (`build.gradle.kts`):
- Uses the `manahive.spring-service` plugin (Spring Boot service)
- Depends on:
    - `hub.hubDomain` (the domain module)
    - `platform.messaging`
    - Spring Boot JDBC starter
    - PostgreSQL driver (runtime)
    - Testcontainers for PostgreSQL (test)

**Source Files**:
- **`HubApplication.kt`** - Spring Boot application entry point. Describes the hub as:
    - The **SYSTEM OF RECORD**: every event from every engine is ingested into the Postgres ledger
    - Provides global order, forensic audit, golden replay, and re-seed source
    - Contains bounded contexts: housing, policy, chronicle, inquiry

- **`LedgerPort.kt`** - The append-only event store interface:
    - `LedgerPort`: append, read by stream, read from global sequence
    - `AppendResult`: Appended, Conflict, or Duplicate outcomes
    - `StoredEvent`: globalSeq, stream, streamSeq, envelope
    - `WatermarkPort`: consumer watermark tracking (effect + mark advance in one transaction)

**Role**: Infrastructure layer that persists all events to PostgreSQL, providing the foundational event store that other engines can replay from.

---

### Summary

The `hub` is the **central nervous system** of mana-hive:
- **hub-domain**: Contains the pure business logic for resolving clinical policies
- **hub-service**: Provides the persistence layer (event store) and Spring Boot application that ingests and stores all events from the platform

Together, they ensure that every clinical decision and event is permanently recorded in an append-only ledger with global ordering, enabling forensic audit, replay, and state reconstruction.
