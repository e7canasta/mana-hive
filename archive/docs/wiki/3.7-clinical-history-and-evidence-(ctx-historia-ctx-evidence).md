This section documents the persistence and management of clinical events, human reviews, and the highlighted evidence pipeline. The system distinguishes between **immutable detections** (ingested from sensors or external IA) and **append-only reviews** (human judgment).

## 1. Clinical History (ctx-historia)

`ctx-historia` serves as the clinical system of record. It separates the lifecycle of a detected incident from the professional evaluation of that incident [docs/contextos/ctx-historia.md12-17](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/docs/contextos/ctx-historia.md?plain=1#L12-L17)

### 1.1. Domain Model and Data Flow

The context is built around two primary aggregates:

- **IncidentDetection**: Immutable evidence of a clinical event (e.g., a fall). It is identified by a `source_record_id` for idempotency [docs/funcional/modelo-dominio/ctx-historia.md11-31](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/docs/funcional/modelo-dominio/ctx-historia.md?plain=1#L11-L31)
- **IncidentReview**: A human verdict on a detection. Multiple reviews can exist for a single detection (e.g., Open -> Under Review -> Closed), but they are never updated, only appended [docs/funcional/modelo-dominio/ctx-historia.md33-42](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/docs/funcional/modelo-dominio/ctx-historia.md?plain=1#L33-L42)

#### Detection vs. Review Entity Space

**Sources:** [crates/ctx-historia/src/lib.rs8-17](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/ctx-historia/src/lib.rs#L8-L17) [docs/funcional/modelo-dominio/ctx-historia.md11-42](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/docs/funcional/modelo-dominio/ctx-historia.md?plain=1#L11-L42)

### 1.2. Idempotent Ingestion

The system enforces idempotency via the `source_record_id`. If an external system sends the same detection twice, the `ingest_in_transaction` method identifies the existing record and returns it with a `duplicate: true` flag rather than creating a new entry [crates/ctx-historia/src/detecciones/sqlite.rs63-77](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/ctx-historia/src/detecciones/sqlite.rs#L63-L77)

- **Endpoint**: `POST /internal/v1/clinical/incidents` [docs/contrato/modulos/historia.yaml14-16](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/docs/contrato/modulos/historia.yaml#L14-L16)
- **Implementation**: `SqliteConnection::ingest_in_transaction` [crates/ctx-historia/src/detecciones/sqlite.rs63-132](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/ctx-historia/src/detecciones/sqlite.rs#L63-L132)

### 1.3. Review Workflow

Reviews are append-only. The "current" state of an incident is determined by the most recent review based on insertion order (`rowid`) to ensure determinism even if multiple reviews occur within the same millisecond [crates/ctx-historia/src/revisiones/sqlite.rs81-87](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/ctx-historia/src/revisiones/sqlite.rs#L81-L87)

**Key Verdicts (`DetectionVerdict`):**

- `fall`: Confirmed fall.
- `not_a_fall`: False positive.
- `uncertain`: Evidence is inconclusive.
- `safe_to_ground`: The resident reached the floor safely (not a clinical fall) [docs/funcional/modelo-dominio/ctx-historia.md37](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/docs/funcional/modelo-dominio/ctx-historia.md?plain=1#L37-L37)

## 2. Evidence Pipeline (ctx-evidence)

`ctx-evidence` manages the highlighting of specific scene events, the grouping of events into timelines, and the definition of recording windows (clips).

### 2.1. Evidence and Timelines

- **Evidence**: A specific event (like a `SceneEvent`) marked for clinical relevance. It includes metadata like `risk_level`, `shift`, and the raw JSON of the event [crates/ctx-evidence/src/lib.rs41-60](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/ctx-evidence/src/lib.rs#L41-L60)
- **Timeline**: A collection of events surrounding an "anchor" event, providing temporal context (events before and after the anchor) [crates/ctx-evidence/src/lib.rs162-180](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/ctx-evidence/src/lib.rs#L162-L180)

### 2.2. ClipWindow Management

A `ClipWindow` defines a period of interest for video/data retrieval. It tracks the `start_time`, `end_time`, and a `close_condition` (e.g., a specific event type that triggers the end of the window) [crates/ctx-evidence/src/lib.rs9-12](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/ctx-evidence/src/lib.rs#L9-L12)

## 3. Data Persistence Model

Both contexts use SQLite via Diesel. Migrations are embedded within the crates to maintain the "no cross-context" rule [crates/ctx-historia/src/lib.rs27-36](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/ctx-historia/src/lib.rs#L27-L36) [crates/ctx-evidence/src/lib.rs21-30](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/ctx-evidence/src/lib.rs#L21-L30)

### 3.1. Key Tables Reference

|Table|Context|Purpose|Invariants|
|---|---|---|---|
|`incident_detections`|`ctx-historia`|Clinical events.|Unique `source_record_id`.|
|`incident_reviews`|`ctx-historia`|Human verdicts.|Append-only; ordered by `rowid`.|
|`evidence`|`ctx-evidence`|Highlighted events.|Links to `scene_event_id`.|
|`timelines`|`ctx-evidence`|Event sequences.|Anchor-based grouping.|
|`clip_windows`|`ctx-evidence`|Recording metadata.|State: `Open` or `Closed`.|

**Sources:** [docs/funcional/modelo-dominio/ctx-historia.md59-95](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/docs/funcional/modelo-dominio/ctx-historia.md?plain=1#L59-L95) [docs/reference/domain.md61-66](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/docs/reference/domain.md?plain=1#L61-L66)

### 3.2. Cross-Context Resolution

Since contexts are strictly decoupled, `ctx-historia` does not use Foreign Keys to `residents` or `beds`. Instead, `mana-app` resolves these **Opaque IDs** using lookup ports during request processing [docs/reference/domain.md79-81](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/docs/reference/domain.md?plain=1#L79-L81)

**Sources:** [docs/reference/domain.md93-95](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/docs/reference/domain.md?plain=1#L93-L95) [crates/mana-app/src/historia.rs8-9](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-app/src/historia.rs#L8-L9)
