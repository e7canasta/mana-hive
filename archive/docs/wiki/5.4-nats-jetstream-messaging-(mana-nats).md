The `mana-nats` crate serves as the central event-driven communication layer for the MANA Hub ecosystem. It provides a structured abstraction over NATS JetStream, facilitating decoupled interaction between the Hub (Event Store), Engine (Digital Twin), Sentinel (Rule Evaluation), and Vigilancia (Alert Management) [crates/mana-nats/src/lib.rs1-8](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/lib.rs#L1-L8)

## NatsBroker Abstraction

The core of the messaging system is the `NatsBroker` struct, which encapsulates the `async_nats::Client` [crates/mana-nats/src/broker.rs9-12](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/broker.rs#L9-L12) It is typically used as a `SharedBroker` (an `Arc<NatsBroker>`) to allow safe sharing across asynchronous tasks [crates/mana-nats/src/broker.rs41-47](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/broker.rs#L41-L47)

### Connection Management

- **Initialization**: `NatsBroker::new(url)` establishes the connection using default `ConnectOptions` [crates/mana-nats/src/broker.rs16-27](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/broker.rs#L16-L27)
- **Health Check**: The `is_connected()` method allows components to verify the underlying NATS connection state [crates/mana-nats/src/broker.rs35-37](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/broker.rs#L35-L37)

## Consumer Groups and Durability

To ensure "at-least-once" delivery and parallel processing, `mana-nats` defines specific consumer group names. These constants ensure that multiple instances of a service (e.g., two Engine pods) share the same message queue for a specific role [crates/mana-nats/src/topics.rs17-41](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/topics.rs#L17-L41)

|Consumer Constant|Group Name|Stream Subscription|
|---|---|---|
|`ENGINE_PERCEPTION`|`engine-processor`|`evt_perception`|
|`SENTINEL_SCENE`|`sentinel-evaluator`|`evt_scene`|
|`VIGILANCIA_NOTIF`|`vigilancia-handler`|`evt_notif`|
|`HUB_PERCEPTION`|`hub-persistence`|`evt_perception`|

## EventSubscriber and Serialization

The `EventSubscriber<T>` is a generic wrapper that handles the boilerplate of stream consumption and JSON deserialization [crates/mana-nats/src/subscriber.rs10-13](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/subscriber.rs#L10-L13)

### Implementation Details

- **Generic Deserialization**: It uses `serde_json::from_slice` to convert NATS payloads into strongly-typed domain events [crates/mana-nats/src/subscriber.rs25-38](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/subscriber.rs#L25-L38)
- **Subscription Methods**: `NatsBroker` provides specialized methods like `subscribe_scene` and `subscribe_notif` which return these wrapped subscribers [crates/mana-nats/src/subscriber.rs41-129](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/subscriber.rs#L41-L129)

### Correlation and Tracing

Events include a `trace_id` field for cross-pipeline correlation [crates/mana-nats/src/publisher.rs110](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/publisher.rs#L110-L110) When the Sentinel produces a `NotificationEvent`, it carries over the `trace_id` from the triggering `SceneEvent` to maintain visibility from perception to notification [crates/mana-nats/src/publisher.rs77](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/publisher.rs#L77-L77)

## Worker Loop Utilities

The `worker_loop.rs` module provides standardized infrastructure for the three stateless worker binaries (`mana-engine`, `mana-sentinel`, `mana-vigilancia`) [crates/mana-nats/src/worker_loop.rs1-3](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/worker_loop.rs#L1-L3)

### Key Functions

1. **`init_tracing`**: Configures `tracing-subscriber` with consistent formatting (no ANSI, includes line numbers) and environment-based filtering [crates/mana-nats/src/worker_loop.rs14-25](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/worker_loop.rs#L14-L25)
2. **`connect_nats`**: A helper that initializes the `NatsBroker`, sets up a broadcast shutdown channel, and spawns the signal handler in one call [crates/mana-nats/src/worker_loop.rs59-64](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/worker_loop.rs#L59-L64)
3. **Graceful Shutdown**: The `shutdown_signal` function handles `SIGTERM` and `SIGINT` (Ctrl+C), ensuring workers can finish processing their current message before exiting [crates/mana-nats/src/worker_loop.rs35-54](https://github.com/pbaalerta-wq/hubp/blob/cc2edd14/crates/mana-nats/src/worker_loop.rs#L35-L54)
